# からだ定点

写真 2 枚（正面・横向き）から姿勢を測り、過去と比べ、次の運動につなげるアプリです。
画像の処理はすべて端末のブラウザの中で行い、外部には送信しません。医療的な診断ではありません。

- 公開ページ: https://moichez.github.io/karada-teiten/
- 対応: Android の Chrome（主な対象）。iPhone の Safari は未確認

## できること

- プロフィール入力（すべて任意、目標がなくても使える）
- 正面・横向きの撮影（カメラ / 写真の選択、セルフタイマー、ガイド枠、水準器）
- MediaPipe Pose Landmarker による骨格推定（端末内）と撮影品質のチェック
- 骨格の点の手動補正（14 点）と再計算
- 正面 10 指標・横向き 12 指標・複合スコア 2 種。測定のばらつきの目安と信頼度つき
- 正面の左右差は「測定のばらつきを超えるか」で判定。横向きの前後の位置は 1 回の測定では判定せず、位置の記録として残して前回からの変化を伝える
- 横向きの背中の輪郭（人の領域の外形）から、背中上部の丸みと腰のすき間の深さを記録（背骨の角度ではない）
- 正面と横向きを 1 枚ずつ撮る測り方。スマホを置いて撮るほか、鏡の前での自撮りにも対応（左右を戻して記録）
- 意識した姿勢（自分が良いと思う姿勢）との比較（結果画面から任意で）
- 分析結果（観測された事実 / 考えられる要因 / 試してみるとよい行動 を分けて表示）
- 過去比較（前回・日付指定・2 件選択・7 / 30 / 90 日の推移、条件差の注意、行動記録との関連）
- ルールベースの運動・ストレッチ提案と実施記録
- 正面と横向きから合成した関節の向きを、標準の人体（マネキン）にのせた 3D と、過去との重ね表示
- 動きを撮る（スクワット・ローイングエルゴ・固定式の自転車）: 横から撮った動画から、1 回（1 本・1 回転）ごとに角度と時間を測る。スクワットは深さ・膝・股関節・上体・すね・しゃがむ / 立ち上がる時間、エルゴはレート・ドライブ / リカバリーの時間・キャッチとフィニッシュの角度・脚 / 上体 / 腕が動く順番、自転車はケイデンス・下死点と上死点の膝・股関節・足首。撮った動画と 3D の体（エルゴ・自転車は目安の器具の形つき）を並べて同じ時刻で再生し、角度のグラフで見られる（スロー・コマ送り）。動画は残すと選んだときだけ端末に保存
- 動きの前回との並べ比べ（1 回を 0〜100% にそろえて、動画・3D と平均の曲線を並べる）
- 動きのコマごとの点の補正（動画の上で点をドラッグ。前後のコマにもなじませる。取り消し・やり直し。直すたびに計算し直す）
- 動きの CSV（コマごと・1 回ごと）と JSON の書き出し
- 3D の体に、種目で一般に主に使われる筋肉の場所を色で示す（教育用の例で、測った値ではない）
- スクワットの推定の重心（動画に重心から床への線）と、股関節と膝の負担の比（仮定を動かした幅の帯つき）、筋肉の要求度の濃淡（3D の色と、伸びながら / 縮みながらの表示）。身長・体重・持つ重さは任意で入れ、入れなければ仮定の値を使って「仮定」と出す。力の大きさ（Nm）は出さない
- スクワットの太ももの傾き（パラレルより深いか）、自転車の下死点の膝に出典つきの目安（25〜35°、止まって測る方法の値）
- エルゴの、脚・上体・腕が動く順番（ドライブの中で、それぞれの速さがいちばん大きい時刻と、1 本をそろえた速さの曲線）。良し悪しは判定しない
- 自転車の、クランクの角度（足首の点の軌跡に当てた円のまわり）ごとの膝・股関節・足首の角度の平均と揺れ
- 動きの結果で、元の動画と推定した 3D の体を、撮ったカメラと同じ向き・大きさで重ね、境目を左右にスライドして見比べる（並べる表示にも切り替え可。動画の書き出しも重ねた形になる）
- スクワットを真正面か真後ろから撮ると、左右の差（腰の横ずれ、膝の間隔 ÷ 足首の間隔、左右の膝の外への開き、肩の傾き）を測る。撮った向き（横・正面・後ろ・斜め）は自動で見分け、体の左右は画面の上の位置から決める
- スクワットのバーの軌道（持つ重さを入れたとき。手首の点で代用）: 動画の上の軌跡、前後のぶれ、いちばん深いところの位置、立ち上がるときの平均と最大の速さ
- 動きを動画（MP4。録画できない端末では WebM）に書き出す: 撮った動画（重ね表示つき）・3D の体・今の値・グラフを縦長の 1 画面にまとめ、再生の速さで録画する。端末の中だけで作り、どこにも送らない
- 結果の画面に、立ち姿勢の 3D（標準の人体）をそのまま表示
- 端末内保存（写真は同意した場合のみ）、JSON / CSV の書き出し、JSON の読み込み
- PWA（ホーム画面に追加、オフライン）

できないこと・未実装は [docs/08](docs/08-verification-and-limits.md) とアプリ内の「できること・まだできないこと」に書いています。

## 起動手順

Node.js 22 以上。

```bash
npm install
```

```bash
npm run dev
```

http://localhost:5173 を開きます。`npm run dev` の前に MediaPipe の WASM が `public/mediapipe/` にコピーされます。

スマホのカメラは HTTPS でしか使えないため、実機では GitHub Pages の公開ページを使います（`main` に push すると自動で更新されます）。

## 構成

```
src/domain    計算ロジック（純粋関数、テスト対象）
src/pose      MediaPipe と画像処理
src/data      IndexedDB（Dexie）とエクスポート / インポート
src/state     画面をまたぐ状態（Zustand）
src/components 共通 UI・骨格表示・補正エディタ
src/screens   画面
tests         単体テスト（Vitest）
```
