# 01. 要件整理と情報設計

アプリ名（仮）: **からだ定点**
同じ条件で定期的に撮影し、姿勢の変化を自分で確かめ、次の行動につなげるアプリ。

## 1. このアプリが解く問題

| ユーザーの状態 | 既存手段の限界 | このアプリが提供するもの |
|---|---|---|
| 姿勢や体の不調が気になるが、何から始めればよいか分からない | 一般論の動画は自分に合っているか分からない | 写真から測った自分の数値と、それに合わせた短いメニュー |
| 運動を始めても続かない | 体重や見た目は短期間では変わらず、手応えがない | 姿勢・疲れ・継続日数など、体重以外の変化を見える形で返す |
| 「猫背」「反り腰」と言われて不安 | 診断のような言い方で不安になる | 観測された事実・考えられる要因・試す行動を分けて、穏やかに伝える |

## 2. 価値の流れ

```
測る → 比べる → 理解する → 行動する → 続ける → また測る
 撮影     過去比較    事実/仮説    メニュー     記録・振り返り   再測定の案内
```

「測って終わり」にしないため、どの画面にも次の行動への導線を置く。

## 3. 機能要件（初期版）

| # | 機能 | 初期版の範囲 |
|---|---|---|
| 1 | オンボーディング / プロフィール | 年齢・性別（回答しない可）・身長・体重・目的（複数）・運動経験・活動量・生活パターン（複数）・睡眠/疲労の自己評価・気になる部位・目標の有無。すべて後から編集可。目標なしでも進める |
| 2 | 撮影 | 正面・側面。カメラ撮影（セルフタイマー・ガイド枠・撮影時の端末傾き記録）と画像アップロード。側面は左右どちらでも可、向きを保持 |
| 3 | 骨格推定 | MediaPipe Pose Landmarker（端末内、IMAGE モード）。33 点の画像座標・ワールド座標・visibility を保持 |
| 4 | 骨格オーバーレイ | 写真上に骨格線と点を表示。補正済みの点は形で区別 |
| 5 | 品質チェック | 人物未検出・全身欠け・小さすぎ・暗い/明るすぎ・ぶれ・向き不一致・極端な傾き・複数人・遮蔽。重大なら再撮影を促す |
| 6 | 手動ランドマーク補正 | 14 点（左右の耳・肩・股関節・膝・足首・かかと・足先）。ドラッグ・拡大鏡・拡大表示・微調整ボタン・元の位置へ吸着・個別/全体リセット・自動再検出 |
| 7 | 再計算 | 補正後に全指標を再計算。補正前の値も保持し差分を記録 |
| 8 | 分析結果 | サマリー・正面/側面切替・写真+骨格・特徴・指標一覧・気になる点・生活習慣との関連仮説・推奨行動・各画面への導線 |
| 9 | 過去比較 | 比較対象選択（最新 vs 前回 / 任意日付 / 任意 2 件 / 7・30・90 日推移）・条件差の注意・写真/骨格の並列とスライダー比較・数値比較・変化の言語化・行動記録との関連・次の提案 |
| 10 | 運動 / ストレッチ提案 | ルールベース。今日のおすすめ・3/5/10 分・疲れた日・最小メニュー・比較結果からの優先。実施記録 |
| 11 | 3D 可視化 | 正面と側面の 2D ランドマークを合成した簡易 3D。マネキン表示・回転/拡大・過去との重ね表示・関連が考えられる部位の参考ハイライト |
| 12 | ローカル保存 | IndexedDB。画像は初期設定で保存しない（同意時のみ保存） |
| 13 | エクスポート / インポート | JSON（全データ）・CSV（測定値）。JSON から復元 |
| 14 | 実装状況の明示 | アプリ内に「実装済み / 未実装」ページ |

対象外: 詳細モード（12 枚測定）、クラウド同期、アカウント、動画解析、医療的評価。

## 4. 非機能要件

- **端末内処理**: 画像・骨格推定・計算はすべてブラウザ内。モデル・WASM・フォントも自サイトから配信し、外部への送信を行わない
- **モバイル優先**: 375px 幅で操作できる。主要ボタンは画面下部、片手で届く位置
- **PWA**: ホーム画面に追加でき、一度読み込めばオフラインでも動く
- **HTTPS 配信**: カメラ利用のため GitHub Pages で配信
- **アクセシビリティ**: 文字コントラスト 4.5:1 以上、タップ領域 44px 以上、ドラッグ操作にはボタンでの代替、色だけで意味を伝えない、動きを減らす設定に従う
- **保守性**: 計算ロジックは UI から独立した純粋関数にし、単体テストで固定する

## 5. 表現ルール（プロダクト全体）

| 書かないこと | 代わりに書くこと |
|---|---|
| ストレートネック、側弯、骨盤のゆがみ（診断名） | 頭部前方位傾向、肩の高さの左右差、骨盤付近の左右差 |
| 猫背です / 反り腰です | 猫背傾向に関連する特徴、反り腰に関連する特徴 |
| 筋肉が硬い / 弱い | 関連が考えられる部位、負担がかかりやすい可能性がある部位 |
| 正常 / 異常、基準値 | 測定のばらつきの範囲内 / 差が見られる（自分の過去との比較が主） |
| 将来こうなります | 仮想シナリオ（初期版では作らない） |

すべての結果画面で「観測された事実」「考えられる要因（仮説）」「試してみるとよい行動」を分けて表示する。医療診断ではない旨は、オンボーディング・結果画面・設定に明記する。

## 6. 情報設計

### 6.1 ナビゲーション

下部タブ（4 つ）+ 中央の主要ボタン。

```
┌────────────────────────────────┐
│  ホーム   比較   [ 測る ]   運動   履歴  │
└────────────────────────────────┘
```

- **測る** は最重要の行動なので、タブ列の中央に大きく置く
- 設定は ホーム右上。3D ビューは 結果・比較から開く（主ナビには置かない）
- URL は HashRouter（GitHub Pages で深いリンクが壊れないため）

### 6.2 画面の関係

```
初回: オンボーディング → ホーム
測定: 撮影ガイド → 正面撮影 → 骨格確認・補正 → 側面撮影 → 骨格確認・補正 → 分析中 → 分析結果
                                                    （側面は省略可）
結果から: 比較 / 3D / 運動提案 / 補正し直す
比較から: 3D 比較 / 優先メニュー / 再測定
運動: 提案一覧 → メニュー詳細 → 実施記録
```

### 6.3 データの見せ方の階層

1. **一言サマリー**（いま何が言えるか）
2. **図**（写真+骨格、定点グリッド、比較の重ね表示）
3. **特徴**（数値の意味を日本語にしたもの）
4. **数値**（指標・単位・ばらつきの目安・信頼度）
5. **根拠**（使ったランドマーク・計算式・限界）— 開いて読む

初心者は 1〜3 で十分理解でき、確かめたい人は 4〜5 まで辿れるようにする。
