実装: [src/domain/metrics/](../src/domain/metrics/)、[src/domain/quality.ts](../src/domain/quality.ts)、[src/domain/traits.ts](../src/domain/traits.ts)
テスト: [tests/metrics.test.ts](../tests/metrics.test.ts)

## 0. 前提と共通定義

### できること・できないこと

| できる（参考値として） | できない |
|---|---|
| 写真上の関節の目印どうしの角度・位置関係 | 骨や関節そのものの位置（MediaPipe の点は皮膚・衣服の外見から推定した位置） |
| 自分の過去の測定との差 | 他人や「正常範囲」との比較（基準値を持たない） |
| 左右差・前後差の「方向」と「大きさ」 | 側弯・ストレートネック・骨盤のゆがみ等の診断 |
| 測定のばらつきを超える差かどうかの判定 | 骨盤の前傾・後傾の角度（骨盤の前後端の目印がない） |
| | 筋肉の硬さ・弱さ、痛みの原因、体重のかかり方の実測 |

### 座標系

- **画像座標**: MediaPipe の正規化座標 `(x, y)` に画像の幅・高さを掛けた **ピクセル座標**。原点は左上、x は右、y は下が正。角度は縦横比のゆがみを避けるため必ずピクセル座標で計算する
- **鉛直の基準**: 画像の縦方向を鉛直とみなす（カメラが垂直に構えられている前提）。アプリ内撮影では端末の傾きを記録し、3° を超えたら注意を出す
- **被写体の左右**: MediaPipe の `left_*` は被写体自身の左。正面写真では、被写体の左は通常は画像の右側に写る。符号は画像の向きに頼らず、ランドマークから求める
  `sLat = sign((L肩.x − R肩.x) + (L股.x − R股.x))`（被写体の左が画像の右なら +1）
- **側面の向き**: `f = sign((鼻.x − 耳.x) + (足先.x − かかと.x))`（顔が画像の右を向いていれば +1）。前方 = `f` の方向
- **側面の近い側**: 左右の耳・肩・股関節・膝・足首・かかと・足先の visibility の平均が高い方を「カメラ側の半身」とし、側面の計算はその側の点だけを使う

### 前処理

1. 各点の信頼度 `v = min(visibility, presence)`（値がなければ 1）。手動補正した点は `v = 1` として扱い、補正済みの印を付ける
2. 計算に使う点のどれかが `v < 0.5`、または画像の外（x, y が 0〜1 の外）にあれば、その指標は **評価不可**
3. 体の大きさの基準
   - `H` = 耳の中点からかかとの中点までの縦の距離（正面）/ カメラ側の耳からかかとまでの縦の距離（側面）
   - `T` = 肩の中点と股関節の中点の距離（胴の長さ）

### 測定のばらつき（不確かさ）

基準値を作らない代わりに、「その差が測定のばらつきを超えているか」を判定する。

- 仮定: 各ランドマークの位置は、縦横それぞれ標準偏差 `σ = 0.005 × H` でずれうる（体の高さの 0.5%。身長 170cm なら約 0.85cm）。これは医学的な基準ではなく、**判定のための工学的な仮定** で、[src/domain/constants.ts](../src/domain/constants.ts) で変更できる
- 計算: 使用する点に上記のずれを乱数で 150 回与えて指標を再計算し、その標準偏差を `uncertainty`（1σ）とする。乱数のシードは固定し、同じ入力からは同じ結果になる
- 判定: `|値| > 2 × uncertainty` なら **差が見られる（noticeable）**、それ以下なら **測定のばらつきの範囲内（within_noise）**
- 比較: `|今回 − 前回| > 2 × √(σ前回² + σ今回²)` なら変化あり

### 信頼度

`confidence = min(使用点の v) × 品質係数 × 指標ごとの上限`

- 品質係数: 向きの不一致 0.6、端末の傾き 0.8、ぶれの可能性 0.8、暗い/明るすぎ 0.85、小さく写っている 0.85、複数人 0.9（該当するものを掛け合わせる）
- 表示: 0.75 以上「高」、0.5 以上「中」、それ未満「低」

## 1. 正面の指標

### F1. 全身の左右傾斜 `front_body_lean`
| 項目 | 内容 |
|---|---|
| 使用点 | 左右の肩(11,12)、左右の足首(27,28)、左右の股関節(23,24)（符号用） |
| 座標系 | 画像ピクセル座標 |
| 前処理 | 共通 |
| 正規化 | 角度なので不要 |
| 数式 | `v = 肩中点 − 足首中点`、`θ = atan2(v.x · sLat, −v.y)`（度） |
| 意味 | 足首の中点から見て、肩の中点が被写体の左（+）/ 右（−）にどれだけ傾いているか |
| 限界 | カメラの傾きと区別できない。立ち方（片脚に体重をかける等）の一時的な影響を受ける |
| 測定不能 | 肩・足首のどれかが評価不可 |

### F2. 肩の高さの左右差 `front_shoulder_tilt`
| 項目 | 内容 |
|---|---|
| 使用点 | 左右の肩(11,12)、股関節(23,24)（T 用） |
| 数式 | `θ = atan2(L肩.y − R肩.y, |L肩.x − R肩.x|)`（度）。正規化値 = `(L肩.y − R肩.y) / T × 100`（%） |
| 意味 | + は左肩が低い、− は右肩が低い |
| 限界 | MediaPipe の肩の点は肩峰そのものではなく、服・髪・腕の位置で動く |
| 測定不能 | 肩のどちらかが評価不可、または両肩の横の距離が H の 5% 未満（正面を向いていない） |

### F3. 骨盤付近の左右差 `front_pelvis_tilt`
| 項目 | 内容 |
|---|---|
| 使用点 | 左右の股関節(23,24)、肩(11,12)（T 用） |
| 数式 | `θ = atan2(L股.y − R股.y, |L股.x − R股.x|)`、正規化値 = `(L股.y − R股.y) / T × 100` |
| 意味 | + は左側が低い。「骨盤の傾き」ではなく、股関節の推定位置の高さの差 |
| 限界 | 股関節の点は骨盤の骨の目印（腸骨稜・上前腸骨棘）ではない。衣服の影響が大きいので信頼度の上限は 0.7 |
| 測定不能 | 股関節のどちらかが評価不可 |

### F4. 頭部の左右傾き `front_head_tilt`
| 項目 | 内容 |
|---|---|
| 使用点 | 左右の耳(7,8)。耳が評価不可なら左右の目尻(3,6)で代用（注記を付ける） |
| 数式 | `θ = atan2(L耳.y − R耳.y, |L耳.x − R耳.x|)` |
| 意味 | + は頭が被写体の左へ傾いている |
| 限界 | 髪で耳が隠れると誤差が大きい。顔の向き（左右への回旋）でも値が変わる |
| 測定不能 | 耳も目尻も評価不可 |

### F5. 体幹の左右偏位（参考） `front_trunk_shift`
| 項目 | 内容 |
|---|---|
| 使用点 | 肩(11,12)、股関節(23,24) |
| 数式 | `(肩中点.x − 股中点.x) · sLat / T × 100`（%） |
| 意味 | 骨盤に対して胸郭が左右どちらにずれているかの参考。+ は被写体の左 |
| 限界 | 胸郭そのものの点はないため、肩と股関節の中点の差で代用している |
| 測定不能 | 肩・股関節のどれかが評価不可 |

### F6. 脚のアライメント（左 / 右）`front_knee_left` / `front_knee_right`
| 項目 | 内容 |
|---|---|
| 使用点 | 股関節・膝・足首（左 23,25,27 / 右 24,26,28） |
| 数式 | 膝の角度 `θ = 180° − ∠(股, 膝, 足首)`、膝が股関節と足首を結ぶ線より外側なら +、内側なら −。正規化値 = 膝から線までの距離 / 脚の長さ × 100 |
| 意味 | + は膝が外へ出る方向（O 脚に関連する特徴）、− は内へ入る方向（X 脚に関連する特徴） |
| 限界 | 写真への投影角度であり、骨の角度（FTA など）ではない。太ももの回旋・膝の曲がり・ゆったりした服で大きく変わる。信頼度の上限 0.7 |
| 測定不能 | 3 点のどれかが評価不可、または脚の長さが H の 25% 未満 |

### F7. 左右荷重の傾向（参考推定） `front_load_shift`
| 項目 | 内容 |
|---|---|
| 使用点 | 肩(11,12)、股関節(23,24)、足首(27,28) |
| 数式 | `c = (肩中点 + 股中点) / 2`、`b = 足首中点`、`(c.x − b.x) · sLat / 股関節の幅 × 100`（%） |
| 意味 | 体の中心が両足の中央より左右どちらに寄っているか。+ は被写体の左 |
| 限界 | **体重のかかり方を測ったものではない**。体の位置の偏りから方向を推測しているだけ。信頼度の上限 0.6 |
| 測定不能 | 使用点のどれかが評価不可、または股関節の幅が H の 5% 未満 |

## 2. 側面の指標

側面は「カメラ側の半身」の点だけを使う（耳 E、肩 S、股関節 P、膝 K、足首 A、かかと Hl、手首 W）。

### S1. 頭部前方位の参考指標 `side_head_forward`
| 項目 | 内容 |
|---|---|
| 使用点 | E、S、P（T 用） |
| 数式 | `θ = atan2((E.x − S.x)·f, S.y − E.y)`（耳-肩ラインの鉛直からの前傾角）。正規化値 = `(E.x − S.x)·f / T × 100` |
| 意味 | + は耳が肩の真上より前にある。値が大きいほど頭が前に出ている方向 |
| 限界 | 臨床でいう頭蓋脊椎角（耳珠と第 7 頸椎）とは目印が違う。肩の点は腕の位置でも動く |
| 測定不能 | E または S が評価不可 |

### S2. 体幹の前後傾 `side_trunk_lean`
| 項目 | 内容 |
|---|---|
| 使用点 | S、P |
| 数式 | `θ = atan2((S.x − P.x)·f, P.y − S.y)`、正規化値 = `(S.x − P.x)·f / T × 100` |
| 意味 | + は肩が股関節より前（前傾）、− は後ろ（後傾） |
| 限界 | 背骨の丸みそのものは見えない |
| 測定不能 | S または P が評価不可 |

### S3. 腕の前方位置（巻き肩に関連する参考特徴） `side_arm_forward`
| 項目 | 内容 |
|---|---|
| 使用点 | W、P、S（T 用） |
| 数式 | `(W.x − P.x)·f / T × 100`（%） |
| 意味 | 力を抜いて立ったときに手首が股関節より前にあるか。肩が内側へ巻いていると腕が前に垂れやすい、という観察上の手がかり |
| 限界 | 腕の置き方で簡単に変わる。肩甲骨の位置は測れない。信頼度の上限 0.5 |
| 測定不能 | W または P が評価不可 |

### S4. 骨盤帯の前後位置 `side_hip_forward`
| 項目 | 内容 |
|---|---|
| 使用点 | A、P、S |
| 数式 | 足首と肩を結ぶ線から股関節までの符号付き距離（前が +）/ H × 100（%） |
| 意味 | 骨盤のあたりが体の線より前に出ているか（反り腰と呼ばれる姿勢の一部で見られる特徴） |
| 限界 | 骨盤の前傾・後傾の角度は測れない |
| 測定不能 | 3 点のどれかが評価不可 |

### S5. 膝過伸展傾向の参考指標 `side_knee_extension`
| 項目 | 内容 |
|---|---|
| 使用点 | P、K、A |
| 数式 | `θ = 180° − ∠(P, K, A)`。膝が股関節と足首を結ぶ線より後ろなら +（伸びすぎの方向）、前なら −（曲がっている方向） |
| 意味 | + が大きいほど膝が後ろへ押し込まれている方向 |
| 限界 | 膝の点は服のしわやふくらはぎの形で動く |
| 測定不能 | 3 点のどれかが評価不可 |

### S6. 体の各部の前後位置 `side_plumb_ear` / `_shoulder` / `_hip` / `_knee`
| 項目 | 内容 |
|---|---|
| 使用点 | E・S・P・K と A |
| 数式 | `(各点.x − A.x)·f / H × 100`（%） |
| 意味 | 足首を通る鉛直線（下げ振り線）から各部がどれだけ前後にあるか。良し悪しの判定はせず、位置関係と変化を示す（状態は「記述のみ」） |
| 限界 | 足首の点は外くるぶしそのものではない |
| 測定不能 | 該当点か A が評価不可 |

### S7. 骨盤の前後傾 `side_pelvis_tilt`
初期版では **推定できない**（状態: unsupported）。MediaPipe には骨盤の前端（上前腸骨棘）と後端（上後腸骨棘）の目印がないため。画面では理由を表示し、代わりに S4 を参考として示す。

## 3. 複合指標（説明可能なスコア）

複合指標は、上の指標を「表示用スケール」で割って平均したもの。表示用スケールは単位をそろえるための値で、**医学的な基準ではない**。自分の過去との比較に使う。

### C1. 猫背傾向スコア `composite_kyphosis`
`(S1角度 / 10° + S2角度 / 5° + S3 / 20%) / 3`（S3 が評価不可なら残り 2 つの平均。S1 と S2 は必須）

### C2. 反り腰関連スコア `composite_swayback`
`(S4 / 3% + S5角度 / 5° + (−S2角度) / 5°) / 3`（S4 と S5 は必須）

いずれも内訳（各成分の値）を画面に表示する。不確かさは同じ乱数摂動の方法で求める。

## 4. 品質チェック

| フラグ | 判定 | 重さ |
|---|---|---|
| `no_pose` | 人物が検出されない | 分析不可 |
| `body_cut_off` | 耳・かかと・足先のいずれかが画像外、または v < 0.5 | 再撮影推奨 |
| `occluded` | 肩・股関節のいずれかが v < 0.5 | 再撮影推奨 |
| `orientation_front` | 正面なのに 肩幅 / T < 0.45 | 再撮影推奨 |
| `orientation_side` | 側面なのに 肩幅 / T > 0.35 | 再撮影推奨 |
| `extreme_tilt` | 足首中点から耳中点への線が鉛直から 10° 超 | 再撮影推奨 |
| `too_small` | H / 画像の高さ < 0.45 | 注意 |
| `low_resolution` | 短辺 < 480px | 注意 |
| `too_dark` / `too_bright` | 平均輝度 < 60 / > 215（0〜255） | 注意 |
| `low_contrast` | 輝度の標準偏差 < 25 | 注意 |
| `blurry` | ラプラシアン分散 < 25（短辺 256px に縮小して計算、目安） | 注意 |
| `device_tilt` | 撮影時の端末の左右の傾き > 3°、または前後の傾きが垂直から 10° 超 | 注意 |
| `multiple_people` | 2 人目が H の 50% 以上の大きさで検出 | 注意 |

数値はすべて経験的な目安で、[src/domain/constants.ts](../src/domain/constants.ts) にまとめてある。

## 6. 生活習慣との関連仮説

プロフィールの生活パターン・活動量・疲労感と、差が見られた特徴の組み合わせで、仮説の文章を出す（[src/domain/hypotheses.ts](../src/domain/hypotheses.ts)）。例:

- 頭部前方位 + デスクワーク / スマホ長時間 → 「画面を見る時間が長いと、頭が前に出た姿勢が続きやすいと言われています。今回の特徴と関係しているかもしれません」
- 肩の左右差 + かばんを片側で持つ → 「いつも同じ側でかばんを持つ習慣が、肩の高さの差に関係している可能性があります」

いずれも「可能性」「かもしれません」と書き、断定しない。該当する生活パターンがなければ仮説は出さない。
