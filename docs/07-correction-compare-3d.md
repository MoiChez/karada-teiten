# 07. ランドマーク補正・過去比較・3D の仕様

## 1. ランドマーク補正

### 対象点（14 点）
左右の耳(7,8)・肩(11,12)・股関節(23,24)・膝(25,26)・足首(27,28)・かかと(29,30)・足先(31,32)。
側面ではカメラ側の半身の 7 点のみを既定で表示し、「奥側も表示」で切り替える。

### 操作
| 操作 | 仕様 |
|---|---|
| ドラッグ | 点をつかんで移動。指で点が隠れないよう、指の上に 2.5 倍の拡大鏡（十字線付き）を表示。誤操作を防ぐため 4px 動くまでは移動を始めない |
| 吸着 | ドラッグで元の検出位置から画像の短辺の 1.2% 以内に戻すと元の位置に吸着（「戻した」扱いで補正済みから外す）。ボタン・矢印キーの微調整では吸着しない |
| 拡大表示 | 1× / 2× / 3× を切替。拡大中は 2 本指またはスクロールで移動 |
| 微調整 | 点を選び、上下左右ボタンで 1 画素ずつ動かす（ドラッグできない人の代替手段）。キーボードでは矢印キーで 1 画素、Shift と一緒で 10 画素 |
| 点のリセット | 選んだ点を検出位置に戻す |
| 全リセット | すべての点を検出位置に戻す |
| 補正済みの表示 | 補正した点は四角、未補正は丸。一覧にも印 |

### データ
- `landmarksRaw` は変更しない
- 補正のたびに `correctionLog` に `{ index, from, to, at }` を追加し、`landmarksCorrected` を更新する
- 保存時に `computedMetrics`（補正後）と `computedMetricsRaw`（補正前）の両方を計算して保存する。結果画面では補正した指標に「補正後」と補正前の値を表示する

## 2. 過去比較

### A. 比較対象の選択
- 「最新 vs 前回」（既定）
- 「最新 vs 日付を選ぶ」
- 「2 つを選ぶ」（履歴から）
- 推移: 直近 7 / 30 / 90 日の折れ線（指標を選択）

### B. サマリー
- 総合: 判定できた指標のうち 改善傾向 / 横ばい / 悪化傾向 / 変化あり（横向きの位置の変化、向きの反転、位置の記録の変化）の件数と、一番大きく変わった項目を 1 文で
- 主な変化 3〜5 件: 変化の大きさ（ばらつきの何倍か）の順
- 条件差の注意（該当するものだけ）:
  - 撮影角度差: 端末の左右の傾きが 5° 以上違う（体が斜めを向いた写真は、品質チェックでその面の指標を出さない）
  - 補正の有無が違う
  - 画像の保存有無が違う（片方は骨格のみの比較になる）
  - 信頼度の差が 0.2 以上
  - 側面の向き（左向き / 右向き）が違う

### C. ビジュアル比較
- 写真の比較: 並べる / スライダーで重ねる（両方の画像が保存されている時のみ。なければ理由を表示）
- 骨格の表示 ON/OFF
- ランドマークの位置比較: 足首の中点を原点、体の高さ H で大きさをそろえ、前回（灰色の破線）と今回（濃い色の実線）を同じ定点グリッドに重ねる
- 補正前 / 補正後の切替
- 3D 比較への導線

### C2. ずれの比較（ゲージ）
結果画面と同じ 7 マスのゲージに、今回（塗りつぶし）と比較相手（点線の枠）を重ねる。中央の帯は測定のばらつきの範囲。身長があれば位置のずれを cm の目安で示す（[05-analysis-logic.md](05-analysis-logic.md) の 3b・3c）。

### D. 数値比較
各指標について 前回値・今回値・差分・変化の向き・信頼度（低い方）を表示。

変化の判定（`preferred = toward_zero` の指標）:
- `||今回| − |前回||` がばらつきの 2 倍を超え、今回の方が 0 に近い → **改善傾向**（差が小さくなる方向と定義。画面にも定義を書く）
- 同じ条件で今回の方が 0 から遠い → **悪化傾向**
- 大きさは同じで向きが変わった → **変化あり（向きが反対に）**
- それ以外 → **横ばい**

横向きの前後の位置（S1〜S5）と複合スコア（C1・C2）は、0 が良い姿勢とは言えないので、改善・悪化とは呼ばない。同じ条件（`||今回| − |前回||` がばらつきの 2 倍を超える）で、0 に近づいたら **小さくなった**、0 から離れたら **大きくなった** とだけ伝える。件数は「変化あり」に数え、画面に横向きの位置の読み方を書く。

記述のみの指標（S6）は「前方へ / 後方へ / 横ばい」だけを示す。

### E. 変化の言語化
テンプレートで生成し、断定しない。例:「肩の高さの左右差は前回より小さくなっています（3.4° → 1.2°）」「頭部前方位の指標は大きく変わっていません」

### F. 行動との関連
2 回の測定の間の期間について:
- 運動の実施回数と実施した日数
- よく行ったメニュー（上位 3 件）
- 疲労感・睡眠の自己評価の変化（期間の最初と最後のコンディション記録）

記録がなければ「この期間の記録はありません」と表示し、記録の方法を案内する。

### G. 次の提案
- **継続推奨**: 期間中によく行い、関連する指標が改善傾向または横ばいのメニュー
- **強化したい**: 悪化傾向または差が残っている特徴に対応するメニュー。横向きの位置が前回より大きくなった特徴も含める（理由は「前回より大きくなっています」と書き、悪化とは書かない）
- **回復優先**: 疲労感が高い / 上がっている時の負担の少ないメニュー
- **再測定のタイミング**: 前回からの間隔と、条件をそろえるヒント（同じ時間帯・服装・場所）

## 3. 3D

### 3D 座標の作り方（2 視点の合成）
写真 2 枚から次のように簡易的な 3D 座標を作る（[src/domain/fusion3d.ts](../src/domain/fusion3d.ts)）。

| 軸 | 元データ | 計算 |
|---|---|---|
| 左右 X | 正面写真 | (点.x − 足首中点.x) · sLat / H_正面 |
| 上下 Y | 正面写真 | (足首中点.y − 点.y) / H_正面 |
| 前後 Z | 側面写真 | (点.x − 足首.x) · f / H_側面（同じ関節の左右に同じ値を使う） |

- 補正後のランドマークを使うので、補正は 3D にも反映される
- 側面がない場合は、正面のワールド座標の z（MediaPipe の推定）を体の高さでそろえて使い、「奥行きは推定値」と表示する
- 正面がない場合は 3D を作らない（側面だけでは左右が分からない）
- 単位は「身長に対する比率」で、実寸ではない

### 人体の表示（マネキン）
[src/three/mannequin.ts](../src/three/mannequin.ts)。合成した関節の位置の「向き」を、標準の人体モデルにのせて表示する。

- **モデル**: Blender と MPFB 2（MakeHuman の Blender 版）で作った標準の人体（男性・女性・中間の 3 種、各約 0.8MB、13,524 頂点）。骨は game_engine リグ（Unreal 形式の 53 本）。作り方は [tools/blender/make_mannequins.py](../tools/blender/make_mannequins.py) にまとめ、同じ手順で作り直せる。MPFB の出力は CC0（自由に使える）
- **モデルの選び方**: プロフィールの性別が男性なら男性、女性なら女性、その他・未回答は中間
- **体の形**: 全員に共通の標準の形。体型・筋肉・脂肪のつき方は推定しない（方針どおり）。骨の長さも標準のまま
- **曲げ方**（最初の姿勢から毎回やり直す）:
  1. 骨盤: 左右の股関節を結ぶ線の向き（前後の傾きは測れないので変えない）
  2. 胴: 股関節の中点→肩の中点の向きと肩の線を、背骨の 3 本（spine_01〜03）に 1/3・1/2・残りと分けて回す。背骨の自然な曲がりは標準の体のまま
  3. 首と頭: 肩の中点→耳の中点の向きを首で、耳の線と鼻の向きを頭で合わせる（付け根がずれているので 3 回くり返す）
  4. 腕と脚: 肩→肘、肘→手首、股関節→膝、膝→足首の向き。点がなければ真下に下ろす
  5. 足: かかと→つま先の向き
  6. 大きさは体の高さ（耳〜かかと）を 1 にし、両足首の中点を合成した位置に置く
- **目印**: 鼻・耳・かかと・つま先は骨の子として置いた空のオブジェクト（lm_番号）、ほかの関節は骨の付け根を使う
- **色**: 明るいグレー。参考ハイライトの部位は、各頂点の骨の重みから求めた濃さで琥珀色をなめらかに混ぜる（関節は隣り合う 2 本の骨の重みの重なり。体の陰影が見えるよう最大 75%）
- **前回**: 同じモデルを前回の姿勢に曲げ、半透明のグレーで重ねる
- **照明**: 画面内の光の板（Lightformer）で作った環境光と、足元の接地影。外部への通信はしない
- **読み込めないとき**（初回にオフラインなど）: 骨格の表示に切り替えて知らせる
- **反映しないもの**: 骨盤の前後の傾き、背中の丸み（輪郭の指標）、手首より先の向き、腕や脚のねじれ

### 骨格の表示
- 「表示: 骨格」に切り替えると、合成した関節の位置そのものを、関節の間を円柱（カプセル）でつないだ形で表示する（頭は球）。前回は破線で重ねる

### 共通
- 足元に床グリッドと、足首の中点を通る鉛直線（下げ振り線）
- 参考ハイライト: 差が見られた特徴のうち差の大きい 2 つについて、主な「関連が考えられる部位」を琥珀色で表示（全身が色づいて意味がなくならないように）。凡例に「負担がかかりやすい可能性がある部位（参考）」と特徴名を書く
- 比較: 過去の姿勢を半透明で重ねる / 切り替える
- 操作: ドラッグで回転、ピンチ・ホイールで拡大縮小、視点ボタン（正面・側面・上・斜め）、リセット
- 動きを減らす設定の時は視点の切替アニメーションをしない
- WebGL が使えない場合は 2D の骨格図を表示
