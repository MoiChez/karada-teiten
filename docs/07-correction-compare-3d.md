# 07. ランドマーク補正・過去比較・3D の仕様

## 1. ランドマーク補正

### 対象点（14 点）
左右の耳(7,8)・肩(11,12)・股関節(23,24)・膝(25,26)・足首(27,28)・かかと(29,30)・足先(31,32)。
側面ではカメラ側の半身の 7 点のみを既定で表示し、「奥側も表示」で切り替える。

### 操作
| 操作 | 仕様 |
|---|---|
| ドラッグ | 点をつかんで移動。指で点が隠れないよう、指の上に 2.5 倍の拡大鏡（十字線付き）を表示。誤操作を防ぐため 4px 動くまでは移動を始めない |
| 吸着 | ドラッグで元の検出位置から画像の短辺の 1.2% 以内に戻すと元の位置に吸着（「戻した」扱いで補正済みから外す）。ボタン・矢印キーの微調整では吸着しない |
| 拡大表示 | 1× / 2× / 3× を切替。拡大中は 2 本指またはスクロールで移動 |
| 微調整 | 点を選び、上下左右ボタンで 1 画素ずつ動かす（ドラッグできない人の代替手段）。キーボードでは矢印キーで 1 画素、Shift と一緒で 10 画素 |
| 点のリセット | 選んだ点を検出位置に戻す |
| 全リセット | すべての点を検出位置に戻す |
| 自動再検出 | 高精度モデルで推定し直す。補正はすべて破棄されるので確認を出す |
| 補正済みの表示 | 補正した点は四角、未補正は丸。一覧にも印 |

### データ
- `landmarksRaw` は変更しない
- 補正のたびに `correctionLog` に `{ index, from, to, at }` を追加し、`landmarksCorrected` を更新する
- 保存時に `computedMetrics`（補正後）と `computedMetricsRaw`（補正前）の両方を計算して保存する。結果画面では補正した指標に「補正後」と補正前の値を表示する

## 2. 過去比較

### A. 比較対象の選択
- 「最新 vs 前回」（既定）
- 「最新 vs 日付を選ぶ」
- 「2 つを選ぶ」（履歴から）
- 推移: 直近 7 / 30 / 90 日の折れ線（指標を選択）

### B. サマリー
- 総合: 判定できた指標のうち 改善傾向 / 横ばい / 悪化傾向 の件数と、一番大きく変わった項目を 1 文で
- 主な変化 3〜5 件: 変化の大きさ（ばらつきの何倍か）の順
- 条件差の注意（該当するものだけ）:
  - 撮影角度差: 正面のずれの推定（ワールド座標の肩の線の回転）または端末の傾きが 5° 以上違う
  - 補正の有無が違う
  - 画像の保存有無が違う（片方は骨格のみの比較になる）
  - 信頼度の差が 0.2 以上
  - 側面の向き（左向き / 右向き）が違う

### C. ビジュアル比較
- 写真の比較: 並べる / スライダーで重ねる（両方の画像が保存されている時のみ。なければ理由を表示）
- 骨格の表示 ON/OFF
- ランドマークの位置比較: 足首の中点を原点、体の高さ H で大きさをそろえ、前回（灰色の破線）と今回（濃い色の実線）を同じ定点グリッドに重ねる
- 補正前 / 補正後の切替
- 3D 比較への導線

### D. 数値比較
各指標について 前回値・今回値・差分・変化の向き・信頼度（低い方）を表示。

変化の判定（`preferred = toward_zero` の指標）:
- `||今回| − |前回||` がばらつきの 2 倍を超え、今回の方が 0 に近い → **改善傾向**（差が小さくなる方向と定義。画面にも定義を書く）
- 同じ条件で今回の方が 0 から遠い → **悪化傾向**
- 大きさは同じで向きが変わった → **変化あり（向きが反対に）**
- それ以外 → **横ばい**

記述のみの指標（S6）は「前方へ / 後方へ / 横ばい」だけを示す。

### E. 変化の言語化
テンプレートで生成し、断定しない。例:「肩の高さの左右差は前回より小さくなっています（3.4° → 1.2°）」「頭部前方位の指標は大きく変わっていません」

### F. 行動との関連
2 回の測定の間の期間について:
- 運動の実施回数と実施した日数
- よく行ったメニュー（上位 3 件）
- 疲労感・睡眠の自己評価の変化（期間の最初と最後のコンディション記録）

記録がなければ「この期間の記録はありません」と表示し、記録の方法を案内する。

### G. 次の提案
- **継続推奨**: 期間中によく行い、関連する指標が改善傾向または横ばいのメニュー
- **強化したい**: 悪化傾向または差が残っている特徴に対応するメニュー
- **回復優先**: 疲労感が高い / 上がっている時の負担の少ないメニュー
- **再測定のタイミング**: 前回からの間隔と、条件をそろえるヒント（同じ時間帯・服装・場所）

## 3. 3D

### 3D 座標の作り方（2 視点の合成）
写真 2 枚から次のように簡易的な 3D 座標を作る（[src/domain/fusion3d.ts](../src/domain/fusion3d.ts)）。

| 軸 | 元データ | 計算 |
|---|---|---|
| 左右 X | 正面写真 | (点.x − 足首中点.x) · sLat / H_正面 |
| 上下 Y | 正面写真 | (足首中点.y − 点.y) / H_正面 |
| 前後 Z | 側面写真 | (点.x − 足首.x) · f / H_側面（同じ関節の左右に同じ値を使う） |

- 補正後のランドマークを使うので、補正は 3D にも反映される
- 側面がない場合は、正面のワールド座標の z（MediaPipe の推定）を体の高さでそろえて使い、「奥行きは推定値」と表示する
- 正面がない場合は 3D を作らない（側面だけでは左右が分からない）
- 単位は「身長に対する比率」で、実寸ではない

### 表示
- 関節の間を円柱（カプセル）でつないだマネキン、頭は球
- 足元に床グリッドと、足首の中点を通る鉛直線（下げ振り線）
- 参考ハイライト: 差が見られた特徴のうち差の大きい 2 つについて、主な「関連が考えられる部位」を琥珀色で表示（全身が色づいて意味がなくならないように）。凡例に「負担がかかりやすい可能性がある部位（参考）」と特徴名を書く
- 比較: 過去の姿勢を半透明で重ねる / 切り替える
- 操作: ドラッグで回転、ピンチ・ホイールで拡大縮小、視点ボタン（正面・側面・上・斜め）、リセット
- 動きを減らす設定の時は視点の切替アニメーションをしない
- WebGL が使えない場合は 2D の骨格図を表示
