## 1. ホーム

- **目的**: いまの状態と、今日やることが 10 秒で分かる
- **構成**: ①最新の姿勢（定点グリッド上の骨格図）と測定日 ②前回からの主な変化 2〜3 件 ③今日のおすすめメニュー 1 件 ④今週動いた日（7 日のドット）⑤今日のコンディション記録 ⑥次の再測定の目安
- **CTA**: 測定がまだ → 「最初の測定をする」／測定あり → 「今日のメニューを始める」
- **空状態**: 測定 0 件 → 骨格の輪郭だけのグリッドと「正面と側面の 2 枚で、今の姿勢を記録します」
- **エラー**: DB を開けない（プライベートブラウズ等）→ 保存できない旨と、設定から確認する導線

## 2. オンボーディング / プロフィール

- **目的**: 提案の精度に必要な情報を、負担なく集める
- **構成**: 5 ステップ（①はじめに・医療診断ではない旨 ②基本情報 ③目的 ④生活と運動 ⑤体調と気になる部位）。進捗バー、戻る、すべて「あとで」でスキップ可
- **目標の扱い**: 「明確な目標はまだない」を選べる。その場合は「まず今の状態を知る」を目的として扱う
- **CTA**: 「次へ」→ 最後は「はじめる」
- **エラー**: 数値の範囲外（年齢 10〜100、身長 100〜230cm、体重 25〜250kg）は欄の下に理由を表示
- **プロフィール編集**: 同じ項目を 1 画面で編集

## 3. 撮影ガイド

- **目的**: 比較できる写真を撮るための条件を揃える
- **構成**: ⓪撮り方（スマホを置いて / 鏡の前で自撮り。前回選んだものが初期値）①撮影条件チェックリスト（撮り方ごとに違う）②今日のコンディション（任意）③前回と条件を揃えるヒント（前回の時間帯）
- **流れ**: 撮り方によらず、正面と横向きを 1 枚ずつ撮る（横向きは省略しない）。意識した姿勢は、結果画面から任意で撮る
- **撮影条件（スマホを置いて）**: 明るさ・無地の背景・カメラは腰の高さで垂直・2.5〜3m 離れる・体のラインが分かる服・いつもどおりに立つ・立ち位置の目印・タイマー
- **撮影条件（鏡の前で自撮り）**: 壁に掛けたまっすぐな姿見（立てかけた鏡は傾いて写る）・鏡から 1.2〜1.5m・スマホは胸の前で縦にまっすぐ（顔を隠さない）・タイマーを使い撮る瞬間は前を見る・スマホを持たない腕は体の横・体の線が分かる服・立ち位置の目印。「鏡に映った姿は左右が反対なので、アプリが左右を戻して記録します」と説明する
- **CTA**: 「正面を撮る」、副: 「写真を選ぶ」
- **注意**: 画像は端末内で処理し、保存設定がオフなら分析後に破棄されることを明記

## 4. 正面撮影 / 側面撮影

- **構成**: カメラ映像 + ガイド枠（頭と足の帯、中心線）、セルフタイマー（オフ/3/5/10 秒）、前後カメラ切替、端末の傾き表示（水準器）、全身検出の表示（「全身が入っています」）
- **側面**: 「左向き / 右向き」を選択（自動推定もし、確認画面で修正可）
- **CTA**: シャッター。撮影後すぐに骨格推定 → 骨格確認へ
- **エラー**: カメラ権限拒否 → 設定の開き方と「写真を選ぶ」への切替／カメラなし → アップロードのみ／モデル読み込み失敗 → 再試行
- **代替**: 「写真を選ぶ」でアップロード（端末のカメラアプリで撮った写真も可。1 枚）。鏡の前で自撮りのときは、選んだ写真も左右を戻して使う
- **枚数**: 1 枚
- **鏡の前で自撮り**: 画面には鏡に映った姿をそのまま出す。撮った写真は左右を反転してから推定・保存する（記録の `mirrorSelfie`）。前回の骨格は画面に合わせて左右を反転して重ねる。タイマー中は「鏡の中の自分の目を見てください」（横向きは「まっすぐ前を見てください」）と出す
- **カメラの映像の向き**: 縦に持っているのに横長の映像が来たら、カメラへの頼み方を変えて開き直す（横長 1920×1440 → 縦長 1440×1920 → 縦横比 3:4）。どれでも横長なら、いちばん高解像度に戻して「離れるか写真を選んでください」と知らせる。映像の大きさを画面に小さく出す
- **前回の位置**: 前回の同じ面の骨格を破線で、今の推定を細い実線で重ねる。写る大きさ・位置が前回と 5% 以上違えば「前回より小さく写っています（カメラから遠い）」などと案内し、合えば「前回と同じ位置です」。前回と写真の縦横比が違うときは表示しない。横向きは前回の顔の向きを案内する。「前回の位置」で表示を切り替える
- **意識した姿勢**: 結果画面から撮るときは、タイトルが「意識した姿勢（正面 / 横向き）」になり、「自分が良いと思う姿勢で立ちます」と案内する。重ねる骨格は同じセッションのいつもの姿勢

## 5. 骨格確認・ランドマーク補正

- **目的**: 誤検出を直し、計算の信頼性を上げる。直すのは任意で、画面にも「そのままでも分析できます」と出す（隠れた点は推測した位置で計算する）
- **構成**: 写真 + 骨格線 + 補正対象 14 点、品質チェック結果（重大/注意）、補正対象の一覧（補正済みに印）
- **操作**: 点をドラッグ（指の上に拡大鏡を表示）、拡大表示（2〜4 倍・パン）、点を選んで矢印ボタンで 1px 単位の微調整、元の位置の近くで吸着、点ごとのリセット、全リセット（最初から高精度モデルで推定するため、再検出のボタンはない）
- **側面**: カメラ側の半身の点だけを補正対象にする（奥側は隠れているため）。表示切替で奥側も見られる
- **横向き**: いつもの姿勢では、正面の確認のあと必ず横向きへ進む（「横向きは撮らずに分析する」は意識した姿勢のときだけ）
- **CTA**: 「補正を保存して再計算」（補正がなければ「この内容で次へ」）。意識した姿勢では、最後に「いつもの姿勢と比べる」
- **エラー**: 人物が見つからない → 撮り直し / 別の写真。重大な品質問題 → 撮り直しを推奨しつつ、続行も選べる（結果には注意表示）

## 6. 分析中

- 保存したあと、結果へ進む

- **構成**: 処理ステップの表示（骨格推定 → 品質確認 → 指標計算 → 提案作成）。各ステップ完了で印
- **エラー**: 失敗したステップと再試行ボタン

## 7. 分析結果

- **構成**（上から）: ①サマリー（観測された主な特徴を 1〜3 文）①b 立ち姿勢の 3D（正面と横向きから合成した関節の向きを標準の人体にのせたもの。指で回せる。斜め・正面・横の視点。前回との重ね表示や骨格の表示は 3D ビューで）②正面 / 側面 切替 ③写真 + 骨格 + 基準線（足元を通る鉛直線、肩と股関節の水平線。横向きは背中の輪郭と、丸み・すき間を測った線も。写真未保存なら骨格のみ。方眼の図にも背中の輪郭を描き、比較では前回の輪郭を破線で重ねる）③b ずれの向きと大きさ（7 マスのゲージ。中央の帯は測定のばらつきの範囲、直前の測定の位置を点線の枠で表示。正面は左右荷重の傾向の足の図も）④主な姿勢特徴（横向きの特徴は「位置の記録」と表示し、差が見られる / ばらつきの範囲内 は付けない）⑤気になる点 ⑥項目別の指標一覧（開くと根拠・式・限界。高精度モードなら 1 枚ごとの値も）⑥b いつもの姿勢と意識した姿勢（下記）⑦生活習慣との関連仮説 ⑧推奨アクション ⑨導線（比較 / 3D / 運動提案 / 補正し直す）
- **表示の分け方**: 「観測された事実」「考えられる要因（仮説）」「試してみるとよい行動」を見出しと色帯で区別
- **CTA**: 「おすすめメニューを始める」
- **空 / 不可**: 評価不可の指標は理由付きで「評価不可」と表示し、隠さない
- **撮り方**: 鏡の前で自撮りした記録は、見出しの下に「鏡の前で自撮り」と出し、写真の下に「左右を戻して記録している・スマホを持つ腕の位置は評価していない」と書く。以前の高精度モード（版 0.6 まで）の記録は「5 枚の平均」と写真ごとの点の揺れを表示する
- **⑥b いつもの姿勢と意識した姿勢**: 未撮影なら説明と「意識した姿勢を撮る」。撮影済みなら、骨格の重ね図（意識 = 実線、いつも = 破線）、ゲージ（意識した姿勢のマス + いつもの姿勢の点線の枠）、事実（差が見られた項目ごとに「ばらつきの範囲まで小さく / 小さくなるが残る / 変わりにくい / 大きくなる / 反対の向きへ」）、仮説、提案（ふだんの意識づけ / 体を動かすメニュー）、撮り直しと点の補正

## 8. 過去比較

- **構成**: A 比較対象の選択 → B サマリー（総合・主な変化 3〜5 件・条件差の注意）→ C ビジュアル比較 → C2 ずれの比較（ゲージに今回と前回を重ねる）→ D 数値比較 → E 変化の言語化 → F 行動との関連 → G 次の提案
- **CTA**: 「優先メニューを始める」
- **空状態**: 測定 1 件 → 「2 回目の測定で比較できます」と再測定の目安
- 詳細は [07-correction-compare-3d.md](07-correction-compare-3d.md)

## 9. 3D ビュー

- **構成**: 3D の人体（標準の体のマネキンを測った姿勢に曲げたもの。プロフィールの性別で男性 / 女性 / 中間）、視点ボタン（正面 / 側面 / 上 / 斜め）、表示（人体 / 骨格）、表示する姿勢（今回 / 前回 / 重ねる。重ねると前回は半透明）、参考ハイライトの凡例、体の形は全員共通で体型を表していないことの説明
- **操作**: ドラッグで回転、ピンチ/ホイールで拡大、ボタンでも同じ操作ができる
- **エラー**: WebGL 非対応 → 2D の骨格図にフォールバック。体のモデルを読み込めない → 骨格の表示に切り替えて知らせる
- 詳細は [07-correction-compare-3d.md](07-correction-compare-3d.md)

## 10. 運動 / ストレッチ提案

- **一覧**: 今日のおすすめ、時間別（3 / 5 / 10 分のセット）、疲れている日、続けやすい最小メニュー、比較結果からの優先。各メニューに「なぜおすすめか」を 1 行
- **詳細**: 手順、時間、難易度、注意点、やってはいけない条件、対象となる傾向。CTA「やった」→ 実施後の記録（感じ方・違和感の有無・メモ）
- **空状態**: 測定がない → 目的と気になる部位だけから提案し、その旨を表示

## 11. 履歴一覧

- **構成**: 月ごとの一覧（日付・正面/側面の有無・補正の有無・主な特徴）、推移グラフへの導線、複数選択で比較
- **空状態**: 「まだ記録がありません」+ 測定へ
- **操作**: 削除（確認あり）、メモ編集

## 11b. 動きを撮る（スクワット・ローイングエルゴ・固定式の自転車）

- **入口**: ホームの「動きを撮る（スクワット・エルゴ・自転車）」→ 一覧。上に「スクワットを撮る」「ローイングエルゴを撮る」「固定式の自転車を撮る」、下に記録（種目・回数と主な 2 つの値）
- **撮影の説明**: 種目（スクワット / エルゴ / 自転車）を上で切り替えられる。種目ごとに置き方を案内する（スクワットは縦向きで腰の高さ、エルゴと自転車は横向きでシート〜腰の高さ。どれも体の真横から 2.5〜3 m、器具が体にかからない側から）。「動画をこの端末に残す」（初期はオフ。残さなくても、ページを閉じるまでは結果で再生できる）。「カメラで撮る」「撮った動画を選ぶ」
- **撮影**: 「全身が写っています / 離れてください」と端末の傾き、縦に持つとよいときの案内。「撮影を始める」で 5 秒の合図（声と音）→ 撮影（最長 20 秒、「撮り終える」で止める）
- **推定中**: 「n / N コマ」と進み具合。「やめる」
- **測れなかったとき**: 理由（体を検出できない・しゃがむ動きが見つからない・途中までしか写っていない）と、撮り直しの導線
- **結果**: 撮った動画（骨格の線を重ねられる。明るい線がカメラ側の半身）と 3D の体（横・斜め・正面）を並べ、同じ時刻で再生する。再生 / 止める、1 コマ送り・戻し、位置のつまみ、速さ（等速・0.5・0.25・0.1 倍）、「n 回目の底」へ移るボタン。下に角度のグラフ（深さ・膝・股関節・上体・すねを切り替え。1 回ごとの区間に帯、いちばん深いところに点、今の時刻に縦線、触るとその時刻へ移る）と、今の時刻の 5 つの値。その下に 1 回ごとの値の表、平均（回ごとの揺れ・前回との差）、撮影の情報
- **動画を残していない記録**: 3D の体とグラフだけを再生する
- **エルゴ・自転車の結果**: 移るボタンは「n 本目のキャッチ」「n 回転目の下死点」。3D にはシート・レール・フットプレート（エルゴ）、クランクの円・サドル・ハンドル（自転車）を、点の動きから置いた目安の形として出す
- **点を直す**（動画があるときだけ）: 「点を直す」でカメラ側の 9 点（耳・肩・ひじ・手首・股関節・膝・足首・かかと・足先）が動画の上に出る。動画は止まり、点をドラッグか矢印キー（Shift で大きく）で動かす。「前後 5 コマにもなじませる / このコマだけ」。直すたびに角度・区切り・平均を計算し直して保存する。取り消す / やり直す（この画面を開いている間）、「直した点をすべて戻す」。直した点は黄色、器具の前提で置いた点は点線の丸。推定した点は書き換えずに残す
- **筋肉の場所**: チェックを入れると、3D の体のうち、その種目で一般に主に使われる筋肉のある場所に色を付け、名前を並べる（あなたの筋肉の働きを測ったものではないと書く）。エルゴ・自転車は場所だけで、濃さは付けない
- **重心と負担（スクワット）**: 動画に、推定の重心（橙の点）から床への点線と、足（かかと〜つま先、青い線）を重ねる。グラフの値に「太もも（傾き）」「重心（真下の位置）」「負担比（股関節 ÷ 膝）」が加わり、負担比は仮定を動かした幅を橙の帯で示す（ほぼ立っているところは線を切る）。筋肉のチェックは「推定した筋肉の要求度を色の濃さで示す」になり、3D の色の濃さが時刻とともに変わる。3D の下に、今の時刻の筋肉ごとの要求度（0〜1 の棒）と「伸びながら / 縮みながら / ほぼ止まって」
- **重心と負担の推定に使う値**（スクワット）: 身長・体重・持つ重さの入力（撮ったときのプロフィールの値が入る。空なら「仮定 170 / 70 / 0」の札、入れれば「入力」の札）と「この値で計算し直す」。その下に「重心と負担は推定です」の説明（測っていないもの、仮定、幅の意味）
- **脚・上体・腕が動く順番**（エルゴ）: 1 本を 0〜100% にそろえた、脚（シートが下がる速さ）・上体（後ろへ開く速さ）・腕（ひじが曲がる速さ）の曲線（その本の最大を 1 にした平均。線の種類と色で分け、いちばん速いところに点と名前）。ドライブの区間に色の帯。下に、それぞれのいちばん速いところが「ドライブの何 %」か。平均の欄にも 1 本ごとに求めた値
- **クランクの角度ごとの曲線**（自転車）: 膝・股関節・足首を切り替え、横軸をクランクの角度（上死点 0°・前 90°・下死点 180°・後ろ 270°）にした平均の線と、回転ごとの揺れの帯。足首の点の軌跡が円にならないときは、出さない理由を書く
- **バーの軌道**（スクワットで持つ重さを入れたとき）: 動画に、その回の始めから今までの手首の点の軌跡（白い線）。平均の欄に、バーの前後のぶれ・いちばん深いところの位置・立ち上がるときの平均と最大の速さ（重さを入れないと出さない）
- **値の幅と目安**: 負担比の値には「条件付きの推定」の札と「仮定を動かした幅」を並べる（表の各回の下にも小さく）。自転車の「膝の曲がり（下死点）」には、出典つきの目安（25〜35°）と、測り方が違うことの説明。膝のグラフにも目安の範囲を点線の帯で示す
- **前回と並べて比べる**（同じ種目の前回があるとき）: 2 つの記録の動画（なければ 3D）を並べ、それぞれの何回目かを選ぶ。1 回の始めから終わりを 0〜100% にそろえて同じ進み具合で再生する。下に平均の曲線（前回は点線）と、平均の差の表（「差が見られる / ばらつきの範囲内」）。撮り方・体の向き・コマ数・手で直したかが違えば、その注意
- **書き出す**: 「コマごとの値（CSV）」「1 回ごとの値（CSV）」「記録そのもの（JSON。動画は含めない）」。端末の中でファイルを作り、どこにも送らない
- **表現**: 正常範囲とは比べない。動きの良し悪しや型（「膝が前に出すぎ」など）は判定しない。将来の予測はしない

## 12. 設定 / プライバシー / データ管理

- **構成**: プロフィール編集、画像の保存（初期オフ、オンにする時に説明と同意）、セルフタイマー初期値、エクスポート（JSON / CSV）、インポート（JSON）、すべてのデータを削除（確認あり）、解析の限界の説明、医療診断ではない旨、実装状況ページ、アプリのバージョン
- **エラー**: インポートの形式違い → どの項目が不正かを表示し、既存データは変更しない
